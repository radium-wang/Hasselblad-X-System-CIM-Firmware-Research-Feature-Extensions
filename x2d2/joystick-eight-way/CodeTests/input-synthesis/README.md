# 八向输入离线代码检查

从仓库根目录运行 `python3 x2d2/joystick-eight-way/tools/check_offline.py`。依赖Python3和带ASan/UBSan的C11编译器；无需固件或设备。

- `test_j8.c`：16组四斜向及触点到达/释放顺序，长按、实体重复、正向/斜向切换、冲突、取消、时钟异常；运行时读写/同步丢失/格式/停止/其他按钮退出与清理。
- `test_linux.c`：编译实际 `j8_linux.c`，通过 `fake_linux_api.h` 替换设备和系统调用；16组接管/失败场景及完整截止退出，检查设备销毁、描述符关闭和解除独占。
- `Fixtures/input-relative.csv`：92条真实方向/SYN事件，仅保留相对微秒时间、类型、键码和状态。原始绝对时间已删除；不是完整原始设备日志。

检查器验证迁入清单SHA，将CSV转换为临时的固定小端24字节事件记录，以人工起点重放同一时间间隔，复用未修改的原回放测试。预期13次斜向按下、162条输出事件，最终中性且清理一次。临时记录和测试程序会自动清理。

结果写到模块 `outputs/offline-checks.json`，不提交生成物。这里的替身检查不构成新的实机运行，也不覆盖厂商权限、输入设备重新枚举或所有GUI页面。
