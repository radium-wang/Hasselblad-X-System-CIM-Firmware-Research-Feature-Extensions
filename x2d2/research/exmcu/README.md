## 证据与复现

本组结论来自原厂固件字节、Thumb/ARM64 静态分析、符号与界面资源，以及此前保存的离线对照。校验专题的 MCU 函数还经过 Ghidra 12.1.4 分析。各专题分别说明证据层级，迁入操作没有访问相机。

原厂固件、提取树、反编译载体、完整反汇编和原始工具日志未随仓库提供。只有校验专题的原厂文件身份和 CRC 可通过本次公开工具直接复核；完整差异分类和函数级结论是已保存研究的摘要，不能仅下载本库重跑全部分析。

工具仅依赖 Python 3.9+ 标准库。从仓库根目录运行，显式传入自行合法取得的文件：

```sh
python3 -B x2d2/tools/inspect_exmcu.py --kind app --input /path/to/exMCU_hb722.cont
python3 -B x2d2/tools/inspect_exmcu.py --kind loader --input /path/to/exMCUloader.cont
```

工具先锁定 1.3.18.1 输入的 SHA-256，再读取容器并复算 CRC；摘要只输出到标准输出，不创建或修改固件，不连接设备。未提供固件时不会伪造检查结果。两条命令均已用本地原厂输入复核通过。

## 状态与限制

这是离线研究归档。CRC 校验、界面符号、输入链分析与实体功能成功是不同证据等级；未进行修改 MCU 镜像的设备传输、刷写、启动或恢复验证。没有公开部署入口或修改固件生成器。

STM32L4xx HAL、FreeRTOS ARM_CM4F 与 Qul 痕迹可确定软件平台线索，不能据此确定 MCU 的完整物理料号。所有静态地址只适用于对应输入，不作为其他版本或设备操作接口。
