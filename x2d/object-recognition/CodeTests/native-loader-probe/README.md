# 原厂库隔离链接诊断源码

适用：X2D 4.2.0；X2D II 1.3.16.2 仅作接口对照。保留独立链接诊断 C 源码及模型容器探针源码，不包含设备包生成、传输、运行或恢复步骤。

`link_probe.c` 限制 CPU、地址空间和运行时长，并对调用做限制；只检查加载／符号，不调用解析出的算法或 AF 函数。`model_container_probe.c` 研究容器接口，使用本地提供的库文件。缺少对应原厂库或运行环境时不能宣称可运行。

原厂库、模型和生成程序均未收录。源码和离线接口分析不能代表正常初始化、推理、帧接入、追踪性能或 AF 联动已通过验收。历史观察见[链接结果](../../research/NATIVE-LOADER-DEVICE-RESULT.md)。
