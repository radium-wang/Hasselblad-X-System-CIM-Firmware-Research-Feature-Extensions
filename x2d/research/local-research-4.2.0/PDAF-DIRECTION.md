# 相位方向扫描与目标位置命令

来源：官方 X2D 4.2.0 `libaaa.so` 静态控制流。没有已验证的全程方向控制安装版本。

`_exec_pdaf_afs_process` 位于 `0x90128`，长度 1872 字节。它包含方向扫描、直接目标位置和过滤后目标位置路径，并非只发送位置命令。

| 位置 | 静态行为 |
|---|---|
| `0x90638..0x906a4` | 根据当前位置是否处于指定区间，选择扫描或位置路径 |
| `0x906bc..0x906e0` | 区间与状态检查；可能进入另一扫描分支 |
| `0x9080c..0x90868` | 第二处方向扫描 |
| `0x9065c`、`0x90824` | 拍照请求 Type2，内部 recording 请求 Type5 |
| `0x90688..0x906a0`、`0x90850..0x90868` | 方向转换后与速度一起排队扫描命令 |
| `0x905d8` | 直接排队目标位置 |
| `0x906e0`、`0x906fc` | 经 `_push_filtered_abs_cmd` 排队位置命令 |

`is_cur_pos_between_start_and_peak` 位于 `0x92ba8`，检查当前位置严格处于相应参考位置和峰值之间。强制此条件成立会改变边界行为，不能称为等效替换。

把所有位置命令改为方向与速度，会将到位控制责任从镜头移到机身。仍需解决动态选档、连续更新、过冲纠正、相位失效、取消对焦、松开操作和行程边界停止。

已定位停止相关符号 `lens_cmd_push_focus_stop_cmd`、`lens_ctrl_stop_focus_motor`、`af_wrap_lens_stop_focus_motor`，但本次检查的相位处理函数没有直接调用它们。这不代表完整原厂流程不会停止，只说明不能凭这一个函数验证新闭环的停止链。

保留原厂位置收尾属于改动较小的候选；它不等于完全取消位置命令，也尚未在此研究中完成安装验证。
