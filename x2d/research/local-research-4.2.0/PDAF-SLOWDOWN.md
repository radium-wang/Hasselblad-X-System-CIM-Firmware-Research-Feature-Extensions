# 相位对焦提前降档条件

来源：官方 X2D 4.2.0 `libaaa.so` 静态分析；哈希见索引。没有当前运行参数或物理制动时间的测量。

`get_pdaf_distance_to_peak` 位于 `0x927b0`，长 812 字节。已识别剩余距离与近期位移驱动的分类，未发现这里输出固定的“减速毫秒数”。

令 P 为峰值参考位置，C 为当前位置，L 为上次位置：

```text
D = abs(P - C)
delta = abs(C - L)
K = lens_ctrl_get_steps_per_fdelta_double(...)

使能／状态门槛不通过：返回 0
D < N_super * delta 或 D < Q_super * K：返回 2
D < N_close * delta 或 D < Q_close * K：返回 1
其余：返回 0
```

各比较为严格小于。函数虽计算 delta × fps，但该乘积在所分析函数中用于日志；实际分类不能改写成“速度乘固定毫秒”。

模式参数块中 N_super、N_close 位于 +0x00、+0x08，Q_super、Q_close 位于 +0x10、+0x18，均为 double。+0x28 的 byte 必须非零，且第三实参按 signed byte 解释后大于该值。第三实参的完整含义尚未核对，不将其直接命名为相位置信度。

`af_get_pdaf_af_mode_params` 入口为 `0xb1088`，选择基础参数 +0x980、+0x9b0、+0x9e0 的三个 0x30 字节块之一。

## 分类如何影响选速

相位 AF-S 流程在 `0x904c4` 和 `0x905ac` 调用分类，随后保存结果。`cdaf_get_scan_speed_type` 在分类非零且对应使能成立时，将类别 1/2 映射到拍照 Type1/Type2，并直接返回。

类别 0 不能等同于无条件 Type0；此时或使能关闭时，还会结合清晰度变化、当前档位和等待计数选速。另有只在提速时等待若干工作帧的逻辑；它不是减速持续时间。

delta 增大可能扩大基于 N×delta 的提前降档距离，但光学阈值 Q×K 不会仅因速度倍率提高而自动改变。该机制不能证明任意倍率下都不会越过焦点；实际使用路径、镜头减速度、通信延迟及终止条件仍需分别核对。
