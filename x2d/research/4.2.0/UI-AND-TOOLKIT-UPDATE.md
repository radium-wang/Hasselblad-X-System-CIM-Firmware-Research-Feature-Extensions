# X2D 界面持久化与一键工具阶段更新

更新：2026-10-06。直接 GUI 实验对象为第一代 X2D 100C 4.2.0 构建 24849。工具的多机型支持需按其独立版本矩阵判断。

## 直接 GUI 显示验收

AF-S／AF-C／MF 三项菜单已在主槽原厂 GUI 路径持久保留并经一次软件重启核对。随后移植二代对焦弹窗标题、说明、布局和图标，保留一代字体及边框；使用一代 Qt 6.4.1 重新编译，没有直接加载二代 Qt 6.8.2 缓存。

取景右侧模式图标修正版保留此前 AF 底块，AF-S 的 S 后无额外白底。三分钟独立试运行中用户确认显示符合要求，正式保留并软件重启后再次确认正常。显示验收覆盖 AF-S、MF 及中文弹窗，不是新的 AF-C 连续对焦质量验收。

最终核对固定文件长度、完整 GUI 哈希、原路径、标签、权限、进程域、缓存指针及启动配置。原厂完整备份保留，临时运行守护退出，系统恢复只读。本公开更新只报告显示结果，不包含设备写入安装链。完整断电冷启动、长期稳定性和 AF-C 后端效果仍未验收。

## 一键工具

独立项目 [x2d-907-one-click-extension-toolkit](https://github.com/radium-wang/x2d-907-one-click-extension-toolkit) 已发布至 0.4.8：

- 安装回执周期刷新，区分文件存在与菜单已验证，并保留中断恢复能力。
- 设置窗口、手动更新和记忆启动检查；下载／安装更新由用户执行。
- 简体、繁体、英文桌面及相机菜单；切换相机文案需重新安装。
- Windows 私有 ADB 监听、进程所有权、关闭与异常退出清理修正；不停止其他程序的 ADB。
- 对焦加速文案及旧镜头提示更新；0.4.8 本身没有改变加速代码或参数。

0.4.8 记录 173 项带本地输入的离线测试通过；干净源码 146 通过、27 跳过。原生 Windows 和相机／镜头行为仍有待验收项，不能从包构建推断实机成功。

0.4.9 为未发布候选：将新弹窗和模式图标接入既有 App 预载路线，带本地输入 184 项测试通过，检查三语言、两／三项切换和模式选择保护。该 App 路线尚未在真实相机验收；直接 GUI 安装通过不能替代它。

## 快门动画与声音

四阶段 400 ms 动画推进到持久安装、原厂音频服务链及默认启动配置。新版单次试听获用户确认，新常驻版软件播放有完成记录；软件显示恢复时间不是光学黑屏时长。完整冷启动、拍摄事件耦合、长期提示音共存仍待验收；素材不随本文再分发。
