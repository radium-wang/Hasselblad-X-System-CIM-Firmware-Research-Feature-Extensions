# X2D 4.2.0：PDAF-only 位置优先影子候选

状态：**仅离线原型；不接入相机、不写 AF 库、不发镜头命令。** 目标机型是第一代 X2D 100C；X2D II 1.3.16.2 只作为算法结构参考。此目录没有 ToF/LiDAR 字段或依赖。

一次原厂 Type3 的 30 秒实机只读采样已取得两次 AF-S 完整状态机和目标位置轨迹，见 [设备结果](DEVICE-RESULT-2026-09-25.md)。采样是原厂运行证据，**不是**本影子算法的实机验证。

## 输入边界

`pdaf_shadow.py` 接收已转换为同一传感器坐标系的 ROI 与相位区域、每区的置信度及**经第一代镜头标定得到的绝对位置估计**。它按实际矩形交集而非序号或固定点数汇总区域；因此不假定 X2D 与 X2D II 的 AF 区域数量、排列、尺寸相同，也不靠裁掉二代数组末尾若干元素。

第二道 `evaluate_temporal_shadow` 要求至少三帧连续、各帧已通过区域/方向检查，且预测位置的差值在显式门限内；否则仍只有原厂路径。一次原厂远处轨迹的最初三个 `target_pos=313、293、172` 会被此离线时间门禁拒绝。后段 `90、83、78` 会给出仅供记录的中值 83，但这**不代表**适合向镜头发 83：原始 Type3 值尚未映射为规范化 `Zone`，阈值也未标定。

眼下**没有**已验证的 `af_pdaf_type3_libaaa_input_s`/输出字段映射、原始置信度标尺、区域几何、方向标尺或 PDAF 离焦量→55V 镜头步数标定。`step_direction` 只是标定后的步数空间符号，不代表原始固件字段。调用者不能把 Type3 原始内存强行转为这里的 `Zone`；输入接口是后续静态分析与只读观测的待完成契约。`Gate` 参数是离线测试显式输入，**不是**二代或一代原厂标定值。

任何无效区域、帧号异常、ROI 覆盖不足、置信度低、目标位置分歧、越过镜头位置范围或行程门限，都不产生建议位置。无论检查结果如何，`stock_path_required=True`；通过检查时也只返回 `shadow_target_steps` 供与原厂最终合焦位置比较，`shadow_only` 不是上机许可。实际回退含义是**保留并继续执行一代原厂 AF 路径和参数**，而不是先发错误镜头命令、事后删代码；事后恢复无法撤销已发生的镜头运动。

## 离线验证

从本目录执行：

```sh
python3 -B -m unittest -v test_pdaf_shadow.py
```

进入任何运行时试验前，至少需要：版本锁定的 Type3 ABI/校验、真实 ROI 几何与帧同步、镜头方向和位置标定、影子预测与原厂合焦终点的多场景误差分布、能在发命令前原子回退的调用边界，以及与旧扫描提速候选互斥的自动恢复。当前均未完成，故没有部署入口。

`device_readonly_probe.py` 是原厂 AF-S 的**只读**采集入口：复用已有完整 AF 原函数哈希/55V 预检，确认 USB 参数仍为 AF-S，然后分别用 `mark` 记设备时间、用 `read --since <mark>` 读取最近的 `target_pos`、PDAF 与 AF 状态日志。它不启动后台记录器、不写 AF 内存或设备文件；相机需要由操作者正常半按。每次读取只取末尾 24 行，因此若日志量大，可能漏帧，不能把日志缺失等同于算法无输出。USB 权限和 `/proc` 读取权限需与已验证的预检环境相同。

若环形日志在人工回应前被冲掉，可用 `capture_stock_pdaf.py start` 在设备私有 `/tmp/pdafsh-<随机>` 启动 30 秒自动结束的有界 `logcat` 记录器，再用 `read --remote-dir ... --since ...` 分别读取状态、目标位置和 Type3 区域日志。用 `cleanup --remote-dir ...` 对照该目录保存的记录器 PID 和进程命令行，只终止匹配的记录器，并删除该实验创建的临时文件和目录。它仅写临时日志，不写 AF 代码、参数或系统分区；记录器自动结束不代表 Type3 字段已标定。第一次 75 秒演练记录器的 AF 状态为零，是人工操作在自动结束后几秒才发生，并非算法故障；其临时目录已清理。

`read_type3_handle.py` 根据第一代原厂 `pdaf_lib_handle` 的 ELF 直接寻址，仅读取其第 0–47 字节并以未解释的 `u32` 偏移输出；每次均先复核机身、镜头、AF-S 和原厂函数哈希，再验证该指针落在进程私有映射中。它用于与原厂日志逐项比对字段，**不是**绕过 Type3 ABI 校验的适配器，也不会修改内存。
