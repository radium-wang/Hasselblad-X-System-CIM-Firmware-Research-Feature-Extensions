# X2D AF Speed Research

This public subset contains:

- `pdaf-scan-type1-candidate/`: current exact-version Type2-to-Type1 scan-request candidate.
- `pdaf-abs-route-candidate/`: rejected historical absolute-position route and its safety findings.
- `verified-x3-fast-only/`: historical description of the exact scope of the multiplier candidate.
- `standalone_handoff/`: offline extraction and validation helpers.
- `original-menu-candidate/`: separately scoped menu source and desktop checks.
- selected research notes and offline tests at this directory level.

Generated function blobs, vendor libraries, runtime memory writers, installers and device logs are intentionally absent. Historical device observations are retained only as sanitized summaries and must not be interpreted as permission to repeat an experiment.
